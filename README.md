# Calculator

A basic calculator application built with Java Swing.

## Requirements

- Java 11 or higher

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/HouariZegai/Calculator.git
   ```

2. Open the project in your Java IDE

3. Run the application
