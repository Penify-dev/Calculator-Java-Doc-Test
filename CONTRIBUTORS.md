## How to Contribute

We welcome contributions from the community! Here are some ways you can contribute:

### Types of Contributions

- **Bug Reports**: Found a bug? Please report it by opening an issue.
- **Feature Requests**: Have an idea for a new feature? Let us know!
- **Code Contributions**: Submit pull requests with bug fixes or new features.
- **Documentation**: Help improve our documentation.
- **Testing**: Help test the application and report issues.

### Contribution Guidelines

1. **Fork the Repository**: Create a fork of this repository to your GitHub account.

2. **Create a Branch**: Create a feature branch for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make Changes**: Implement your changes following our coding standards:
   - Follow Java naming conventions
   - Write clear, commented code
   - Add tests for new functionality

4. **Test Your Changes**: Ensure your changes don't break existing functionality:
   ```bash
   mvn clean test
   ```

5. **Commit Your Changes**: Write clear commit messages:
   ```bash
   git commit -m "Add: Brief description of your changes"
   ```

6. **Submit a Pull Request**: Push your changes and create a pull request with:
   - Clear description of changes
   - Reference to any related issues
   - Screenshots if UI changes are involved

### Code Style Guidelines

- Use 4 spaces for indentation
- Follow Java naming conventions (camelCase for variables/methods, PascalCase for classes)
- Include JavaDoc comments for public methods
- Keep methods concise and focused
- Use meaningful variable names

### Getting Help

If you need help contributing, feel free to:
- Open an issue with your question
- Contact the maintainers directly
- Check existing issues and pull requests for similar topics
